## Projects

### SmartStudy — web application, 2025 to present

A study planner for school and university students. Subjects, tasks, a timetable
that can be imported from a photo using OCR, real-time chat with classmates, and
flashcards. React 19, Vite and Tailwind CSS, with Firebase Auth for accounts and
Firestore listeners so data stays live across devices. The interface and the copy
are in Slovenian.

- Live: https://smartstudyslo.vercel.app/
- Source: https://github.com/NoctsWRLD/SmartStudy (public)

### NSA_REACT — full-stack store, 2024

A React client over an Express API backed by MongoDB. Registration and login use
bcrypt-hashed passwords. Endpoints cover listing and creating products, with
users and products collections. CORS and dotenv for configuration. The source is
not published.

### MovieDB — desktop application, 2024

A movie catalogue in C# with WPF. A Movie model, separate windows for adding and
editing entries, and a settings screen. The source is not published.

### Odkup rabljenih vozil — marketplace, 2023

A used-car marketplace in Slovenian. PHP over SQL with a shared database handler
and a functions file, and separate include files for registration, login and
logout. Listings carry reviews and ratings. The source is not published.
